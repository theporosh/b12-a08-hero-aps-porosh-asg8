## Project name : b12-a08-hero-aps-porosh-asg8

 ### Purpose : Hero IO is a responsive web application that allows users to explore, search, and install apps. The platform showcases app data with interactive features such as app ratings, reviews, downloads, and installation tracking. It emphasizes a clean UI/UX design inspired by Figma mockups while providing a fully functional experience for users on all devices..

 ### live URL: https://dulcet-brioche-f685fc.netlify.app/

 ### key features: In this hero apps you can find
 

 1. Provide a platform to showcase and explore apps.

2. Allow users to search, filter, and view detailed app information.

3. Enable users to "install" apps virtually and manage installed apps via localStorage.

4. Demonstrate modern frontend development skills using React, TailwindCSS, and Recharts.

5. Ensure a production-ready, fully responsive, and error-free web application.
 
 

 ### npm package
 1. recharts
 2. react-toastify
 3. React Icons
 
 

 ## Technologies Used

Frontend: React.js, React Router

Styling: TailwindCSS, CSS

Charts: Recharts

State Management: React Hooks, localStorage
